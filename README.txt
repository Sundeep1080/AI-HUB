AI Hub, installable app
1. Host this folder: go to app.netlify.com/drop and drag the folder in. (GitHub Pages also works.)
2. Open the https link on your phone. Chrome: menu > Install app. iPhone Safari: Share > Add to Home Screen.
3. First planner use asks for an OpenRouter key (openrouter.ai). It stays on your device only.
Change the AI model: edit MODEL near the top of the script in index.html.
